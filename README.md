# LATM Website

**LATM** = **Lab of Atomic-Scale Thermophysics and Mechanics**.

This website keeps the reference site's visual layout, typography, spacing, responsive behavior, and slider framework while using an English-only first-stage homepage for Wenwu Jiang's group at USTC.

## Current identity
- Lab: Lab of Atomic-Scale Thermophysics and Mechanics (LATM)
- PI: Wenwu Jiang
- Institution: University of Science and Technology of China (USTC)
- Main methods/topics: machine-learning interatomic potentials, thermal/phonon transport, and atomic-scale interfacial friction/mechanics

## Run locally
- Windows: double-click `start.bat`
- Linux/macOS: run `bash start.sh`
- Then open `http://127.0.0.1:8000/`
